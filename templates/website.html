Problem & Objectives

Bridging navigation gaps through local convolutional neural networks.

The Visual Challenge

Conventional aids (like walking canes) alert users to direct objects on the ground but cannot classify what those obstacles are (stairs, chairs, humans). Most modern smartphone-based visual apps run classifications via cloud APIs, exposing user privacy and failing inside remote locations where network pings fail.

Proposed Solution

Our system captures real-time video, processes it on-device using a custom-calibrated YOLOv8 structure, estimates object range distances, and outputs thread-safe voice warnings directly. Caretakers log details and adjust settings locally.

System Core Specs

Key Advanced Features

Our enhancements that elevate this work above traditional blind assistant designs.

Calculates approximate range using bounding box scaling logic. Speaks ranges alongside object labels (e.g. "Chair at 1.8 meters").

Caretaker Emergency SOS Pipeline

How the system safeguards the visually impaired user during emergency events on the road.

1. Trigger Action

User presses **'S'** on keyboard (or walking cane button) during navigation loop.

2. Location Capture

System reads user's current spatial GPS coordinates (longitude/latitude).

3. Contact Lookup

SQLite queries caretaker phone records from `emergency_contacts` table.

4. Alert Broadcast

Dispatches mock SMS alerts with active coordinate map links, logging details to SQLite history.
